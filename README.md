# 🦷 SmileCare Dental Hospital — Patient Website

> **"Advanced Dental Care. Gentle Treatment. Confident Smiles."**

A modern, premium, and 100% mobile-first public-facing dental hospital website built for patients to explore treatments, hospital facilities, certified doctor profiles, reviews, and book appointments seamlessly.

---

## 🌟 Key Features

- **📱 100% Mobile-First Responsive Design**:
  - Sticky mobile thumb action bar (**Call Now**, **WhatsApp Us**, **Book Appointment**).
  - Native bottom-sheet modals for treatment details and doctor profiles.
  - Large touch targets (44px+) and iOS auto-zoom prevention.
  
- **🏥 Patient-Centric Architecture**:
  - **Hero Section**: Trust metrics, painless operatory imagery, and floating reassurance badges.
  - **About the Hospital**: 6 core clinical highlights, interior lounge photography, and quality charter.
  - **Our Dental Services**: 8 detailed treatments (General Dentistry, Root Canal, Implants, Whitening, Orthodontics, Cosmetic, Pediatric, Wisdom Tooth).
  - **Hospital Facilities**: 12 modern infrastructure cards with interactive 3D CBCT, Sterilization, and Lounge visual showcase.
  - **Meet Our Doctors**: MDS specialists (Dr. Ananya Sharma, Dr. Rahul Verma, Dr. Priya Singh) with consultation timings and profile dialogs.
  - **4-Step Patient Journey**: First-visit guide designed for anxious patients.
  - **Patient Reviews**: 4.9/5 verified rating badge with patient testimonials.
  - **Real Before & After**: Realistic clinical transformation showcase with medical disclaimer.
  - **Online Appointment Booking**: Instant client-side validation, interactive time slots, date picker, and confirmation voucher with reference token.
  - **Emergency & Fast Contact**: Rapid-response priority contact for acute dental pain and injuries.
  - **Interactive FAQ Accordion**: Answers to the top 9 most common dental patient questions.
  - **Location & Hours**: Embedded Google Maps view, directions, timings, and contact options.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 (Clean modern healthcare palette: White, Navy Blue `#0f2b48`, Soft Sky Blue, Subtle Teal)
- **Icons**: Lucide React
- **Typography**: Google Fonts (*Plus Jakarta Sans* & *Outfit*)
- **State & Data**: Centralized configuration architecture (`src/data/dentalData.js`) for rapid 5-minute client rebranding.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/satishje62-sys/dental_demo.git
cd dental_demo
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
